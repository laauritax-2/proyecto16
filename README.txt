PROYECTO 16 - DESPLEGABLE PERSONALIZADO (CUSTOM DROPDOWN)

Este proyecto se realizó con HTML, CSS y JavaScript, tal como indica el PDF.

COMO ABRIRLO
1. Descomprime el archivo ZIP.
2. Abre la carpeta Proyecto_16_Custom_Dropdown en Visual Studio Code.
3. Abre el archivo index.html con Live Server.
   También puedes abrir index.html directamente en el navegador.
4. No necesita npm ni instalar librerías.

ARCHIVOS
- index.html: contiene el botón, el texto y la lista de opciones.
- style.css: contiene los colores, tamaños, posiciones y diseño adaptable.
- script.js: controla la apertura, selección y cierre del desplegable.

COMO FUNCIONA
- Al iniciar, se muestra un texto de marcador de posición.
- Al pulsar el botón, aparece la lista de opciones.
- Al seleccionar una opción, su nombre aparece en el botón.
- La lista se cierra después de seleccionar.
- La opción elegida queda resaltada.
- También se puede cerrar haciendo clic fuera o pulsando Escape.

REQUISITOS DEL PDF
- Estado predeterminado con texto de marcador de posición.
- Estado abierto que muestra las opciones.
- Estado seleccionado que muestra el elemento elegido.
- Cerrar el menú después de seleccionar.
- Resaltar la opción seleccionada.
- Uso de manipulación del DOM y eventos de JavaScript.

Los comentarios están incluidos en la mayoría de las líneas para facilitar la explicación en clase.
